# Игра "Управляй котом через Telegram"

## Описание проекта

Игроки управляют котами дистанционно через Telegram-бота. Игра состоит из трех компонентов:

1. **Flask-сервер** - игровой сервер с базой данных
2. **Игровое окно** - визуализация игры через pgzero
3. **Telegram-бот** - интерфейс управления для игроков

## Основной функционал

### Управление через бота
- По команде `/join` бот:
  - Отправляет клавиатуру управления
  - Создает игрока на сервере
- Кнопки управления перемещают кота по полю

### Игровой процесс
- Коты перемещаются по клеточному полю 32x32 пикселя
- На поле появляются монетки в случайных местах
- При сборе монетки:
  - Увеличивается счет игрока
  - Появляется новая монетка

### Визуализация
- Плавное перемещение котов между клетками
- Спрайтовая анимация движения (шевеление лапок)
- Над каждым котом отображается Telegram-ник владельца

### Данные игроков
Для каждого игрока хранится:
- Имя (ник в Telegram)
- Позиция на поле (X, Y)
- Время начала игры
- Количество собранных монет

### API сервера
Flask-сервер предоставляет:
1. API для взаимодействия бота и игрового окна
2. Таблицу лидеров (имя, длительность игры, счет)
3. Информацию о разработчике

## Технические требования
- Используемые библиотеки: `flask`, `sqlite3`, `telebot`, `pgzero`
- Запрещено использование Pygame
- Код должен соответствовать PEP8
